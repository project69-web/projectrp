# 🌆 PROJECT CITY RP - Website

Website resmi untuk **PROJECT CITY Roleplay Server** berbasis GTA V (FiveM).
Menampilkan informasi server, berita, aturan, dan panduan bergabung.

---

## 🚀 Fitur Utama

* 🏠 **Homepage** - Landing page utama server
* 📰 **News System** - Update berita dari file JSON
* 📜 **Rules Page** - Peraturan server
* 🏙️ **Sejarah Kota** - Lore & timeline PROJECT CITY
* 👥 **Owner Team** - Informasi tim developer/server
* 🎮 **Join Page** - Link Discord & cara bergabung

---

## 🛠️ Teknologi

* HTML5
* CSS3 (Custom UI)
* JavaScript (Vanilla)
* JSON (Data berita)

## ⚙️ Cara Menjalankan (Local)

Gunakan Live Server di VS Code:

1. Install extension **Live Server**
2. Klik kanan `index.html`
3. Pilih **Open with Live Server**

---

## 🌐 Deploy Online (GitHub Pages)

1. Upload project ke repository GitHub
2. Masuk ke **Settings → Pages**
3. Pilih:

   ```
   Deploy from branch → main / root
   ```
4. Website akan online di:

   ```
   https://username.github.io/project-city/
   ```

---

## ⚠️ Catatan Penting

* Jangan buka file langsung (`file://`) karena:

  * `fetch()` tidak akan jalan
* Gunakan hosting atau Live Server
* Pastikan path file sesuai struktur folder
